❓ FAQ Singkat

Apakah ini tiket sungguhan?

Tidak. Semua jadwal, harga & promo adalah simulasi untuk demo tugas Struktur Data.

Apakah data saya disimpan?

Tidak. Tanpa database — semua hilang saat reload, jadi privasimu aman.

Bagaimana urutan harga bekerja?

Bubble Sort manual mengurutkan 4 mode (Termurah, Termahal, Awal, Tercepat). Setiap banding & tukar tampil di Log Bubble Sort.

Di mana log sorting & searching?

Di halaman Cari: Log Bubble Sort selalu tampil, dan Log Linear Search muncul saat kamu mengetik di kolom cari cepat.

Tentang Kami

TRAVELUX — More Journey, More Story.

TRAVELUX adalah proyek individu mata kuliah Struktur Data (tema NIM Genap: Ticketing). Aplikasi web pemesanan tiket pesawat, kereta, dan bus yang berjalan 100% di browser tanpa database — tanpa backend.

  • Pencarian pesawat, kereta & bus dalam satu aplikasi
  • Filter harga, operator & jam + urutan otomatis
  • Tanpa database: reload kembali baru, privasi aman

🧠 Struktur Data di Balik TRAVELUX

Bukan sekadar tampilan — ini bukti Array, Struct, Pointer, Sorting, dan Searching yang benar-benar dipakai aplikasi.

ARRAY

Array of Struct

70 tiket disimpan berurutan di satu array. Setiap kartu menampilkan Array[n] sebagai indeks aslinya.

tickets[0] … tickets[69]
tickets[12] → struct tiket
STRUCT

Struct Tiket

Satu tiket = satu struct dengan field id, operator, asal, tujuan, harga, dan lainnya.

struct Tiket {
  int id; char operator[24];
  char asal[24], tujuan[24];
  int harga, durasiMenit;
};
POINTER

Pointer / Reference

currentTicket menunjuk struct yang dipilih. JavaScript memakai reference (bukan alamat memori mentah), jadi perubahan objek ikut terlihat.

let currentTicket → Tiket[n]
let alias = currentTicket; // reference
